# TBESH 핵심 뜻(Gloss) 한국어 옮기기 지침

입력: gl_in/inNN.json — 항목 목록. 각 항목 {"k": dStrong 번호, "heb": 히브리어, "tr": 음역, "mo": 품사 코드, "gl": 영어 핵심 뜻, "hint": 참고용 영어 뜻풀이 또는 기존 한국어 사전 조각}
출력: gl_out/outNN.json — {"k": "H0001G", "ko": "아버지"} 형태의 목록. **입력 항목 수와 같아야 하고 순서도 같아야 한다.** 빠뜨리지 말 것.

## 원칙
- `gl`(영어 핵심 뜻)을 **짧은 우리말 핵심 뜻**으로 옮긴다. 1~4어절. 사전 뜻풀이가 아니라 '핵심 뜻 한 줄'이다.
- `hint`는 참고만 한다. hint 내용을 옮기지 말고 `gl`을 옮긴다.
- 교회 성도가 읽을 쉬운 우리말. 전문 용어는 피한다.
- 동사(mo가 H:V / A:V)는 '~하다' 꼴. 예: "to perish" → "멸망하다", "be willing" → "기꺼이 하다".
- 명사는 명사형. 형용사는 '~한'. 감탄사는 느낌이 살게("pain!" → "아이고!").
- 영어 핵심 뜻에 여러 뜻이 쉼표로 있으면 우리말도 쉼표로("fresh, young" → "신선한, 어린").
- 괄호·물음표·하이픈 등 원문의 표시는 뜻이 통하게 살린다. "(Huram)-abi" → "(후람-)아비", "father of" → "~의 아버지".
- **사람·땅 이름(mo가 N:으로 시작)은 개역개정 성경 표기**를 쓴다: Abraham→아브라함, Jerusalem→예루살렘, Manasseh→므낫세, Philistines→블레셋, Zeror→스롤, Maacah→마아가, Kish→기스. 개역개정 표기를 확실히 모르는 드문 이름은 히브리어 음에 가깝게 우리말로 적되 개역개정 관례(끝 자음 받침 처리 등)를 따른다. hint에 한국어가 있으면 그 표기를 우선 쓴다.
- 이름에 수식이 붙으면 함께 옮긴다: "(Valley of) Sorek" → "소렉 (골짜기)", "Abi" → "아비".
- 민족 이름(mo 끝에 G): "Canaanite" → "가나안 사람", "Jebusites" → "여부스 사람".
- 여러 항목의 gl이 같아도 각각 다 적는다.
- 영어를 남기지 않는다(예외: 원문에 있는 H번호는 그대로).

## 작업 방법
- 파이썬으로 입력을 읽고, 번역 결과를 코드 안에 목록으로 써서 출력 파일을 만든다. 출력 뒤 `len(in)==len(out)`과 k 순서 일치를 반드시 검사하고, 한글이 전혀 없는 ko가 있으면 고친다(숫자·기호만인 경우 제외).
