# Android Chrome 실기기 점검 절차 (2026-10-21 갱신) — 아직 **한 번도 실기기로 돌리지 않음**

지금까지의 모바일 수치는 전부 에뮬레이션(Playwright Pixel 5, 360/390/430px, CPU·네트워크 조절)이다. 아래는 목사님(또는 신학생 1명)이 실제 Android 휴대전화의 Chrome 에서 30~40분에 할 수 있는 점검표. 결과는 `docs/REPORT_android_<날짜>.md` 에 그대로 적는다(통과/실패/메모). **실기기 결과가 없으면 "실기기 통과"라고 쓰지 않는다.** 이 문서의 '결과' 칸이 비어 있으면 그 항목은 미수행이다.

**기록 보존 우선**: 저장소를 비우는 시험(1번)과 메모를 만드는 시험(6·16번)은 **시크릿 창 또는 시험용 Chrome 프로필**에서 한다. 평소 쓰는 Chrome 에서 하려면 먼저 기록 탭 → JSON 백업을 내려받는다. 시크릿 창은 닫으면 기록이 사라지므로 시험 중에는 닫지 않는다.

준비: Android 휴대전화 + Chrome 최신 · 주소 https://aqedah.github.io/MILALWV/ · 모바일 데이터(Wi-Fi 아님)로 한 번, Wi-Fi 로 한 번 · 기기 정보(모델·Android·Chrome 판)와 날짜를 적기. 커밋: 점검한 날의 `git log -1` 해시.
