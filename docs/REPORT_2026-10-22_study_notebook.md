# 본문 연구 노트 · 도구 문구 정리 · 장르별 질문 · 옆 노트 — 2026-10-22

GPT의 연구 탭 평가(신학생·설교 준비 관점)를 검토한 뒤, 목사님이 '적용 칸 포함, 모든 단계 실행'을 승인했다.

## 1. 도구 문구 정리 — 앱이 찾은 단서와 사용자의 판단을 나눔
- **흐름 도구 이름**
  - 장면이 열리는 곳 → **장면이 바뀌는 단서**
  - 흐름이 멈추는 문장 → **서술 흐름이 바뀌는 단서**
  - 누가 주어인가 → **주어로 나온 이름**
  - 화자 도구 안의 '인물의 눈으로 보는 곳' → **서술 속의 '보라'**
- 네 도구 모두 결과 위에 **찾은 규칙 / 판단은 본문에서** 상자를 둔다. 어제 장면 도구에 넣은 '뺀 곳과 이유'를 다른 도구에도 넣었다.
  - 화자: 모으지 않은 '보라'(인물의 말 안, 율법·시 등)를 보여 준다.
  - 전환: 같은 종류의 절이지만 서술이 아니라서 모으지 않은 곳을 보여 준다.
  - 인물: 숨은 주어와 대명사 주어(개수 표시)는 세지 않았다고 밝힌다.
- **비교 요약**
  - '뚜렷한 언어 신호가 있습니다'를 사실("두 본문에 같은 표현이 많이 겹칩니다")로 바꿨다.
  - 그 아래에 판단을 따로 적는다: "이 겹침이 인용·암시·재진술의 증거인지는 판단이 필요합니다 — 같은 전승, 흔한 관용구, 같은 문체에서도 말은 겹칠 수 있습니다."

## 2. 본문 연구 노트(연구 탭 → '본문 연구 노트', 연구 첫 화면 맨 위 입구)
- **연구 만들기:** 제목, 본문 범위(예: `욘 1:1-3, 3:1-3`, 다른 책은 `;`로), 연구 질문.
- **연구를 켜 두면** 본문 탭과 연구 탭 위에 "지금 연구 중 · 제목 · 근거 N" 띠가 보인다.
  - 그동안 새로 쓰는 절·구간 메모, 검색 메모, 비교 '내 판단', 본문에서 고른 '노트에 추가', 낱말 메모가 이 노트에 모인다.
  - 메모 창에 "지금 연구 중인 노트에 담깁니다"라는 안내가 뜨고, 표시를 지우면 담지 않는다.
  - 검색 결과의 '메모' 단추는 '노트에 담기'로 바뀐다.
- **연구 화면:** 연구 질문, 무엇을 관찰해 볼까요?(3절), **관찰한 것**, **내 해석**, 이 범위의 다른 메모 '담기', **중간 결론 · 남은 질문 · 적용**. 칸은 쓰는 대로 저장된다.
- **내보내기:** Markdown 복사·내려받기, 인쇄·PDF(근거 본문 포함).
  - '설교 준비용 머리말'을 고르면 순서가 1. 본문 근거 → 2. 본문의 뜻 → 3. 중심 주장 → 4. 더 살필 것 → 5. 오늘의 적용으로 바뀐다.
  - 끝에 "본문 근거는 BHSA 관찰, 해석·결론·적용은 작성자의 판단"이라고 적는다.
  - 자동 생성(설교 대지 등)은 하지 않는다.
- **저장 방식(규칙 변경 없음)**
  - 연구 자체(제목·질문·범위·칸)는 이 기기 localStorage `milal-studies`에 둔다.
  - 메모와는 이미 있는 **표시(태그) 칸의 "연구: 제목"** 으로 잇는다. 기록 형식과 Firestore 규칙은 그대로다(표시 20개 이하 규칙 안).
  - 낱말 메모(이 기기 전용)는 노트가 번호를 기억한다.
  - 제목을 바꾸면 메모의 표시도 함께 바뀐다.
  - 연구를 지우면 노트만 지우고, 메모는 남긴 채 표시만 뗀다.
- **백업:** JSON 백업에 `studies`가 들어간다. 복원 때는 id별로 더 새 판을 남긴다.

## 3. 본문과 노트 함께 보기
- **넓은 화면(1180px 이상):** 본문 탭에서 오른쪽에 노트가 나란히 붙는다. 근거 5개, 중간 결론·남은 질문·적용을 바로 쓸 수 있고, '옆 노트 닫기/노트 옆에 보기'로 켜고 끈다.
- **휴대전화:** 띠의 '노트'를 누르면 본문 위에 노트 창이 열린다. 같은 칸을 바로 쓰고, 닫으면 본문 그 자리로 돌아온다.

## 4. 장르별 '무엇을 관찰해 볼까요?'
- **장 단위로 나눈 대략의 갈래:** 이야기·시·지혜·예언·율법.
  - 예: 창 49 시, 출 20–23 율법, 욥 1–2·42 이야기 / 3–41 지혜, 사 36–39 이야기, 렘 52 이야기, 단 7–12 예언, 욘 2 시.
- 갈래마다 질문 4–5개를 두고, 질문마다 기존 도구(반복·장면·화자·전환·인물·낱말 용례·비교) 또는 조건 카드 검색(2인칭 동사, 명령형, '코 아마르', '로+미완료', '키')을 연결했다.
- 노트에서 누르면 노트의 본문 범위로 연다.
- 연구 첫 화면에는 지금 장의 질문 3개를 보인다.
- 화면에 "갈래는 대략의 구분이고 질문은 관찰 안내, 답은 본문에서"라고 적었다.
