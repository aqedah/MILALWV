# 사용자 경험 점검 — 첫 판(2026-10-19, e2f50c6/7034218)과 현재(c240417) (한 쪽)

지시 10 작업 A. 긴 감사 보고 대신 한 쪽으로 줄였습니다(목사님 결정). 두 판 모두 비판적으로 봅니다. 기준 질문: **"나는 이 앱에서 무엇을 할 수 있고, 지금 무엇을 해야 하는가?"**

## 2. 왜 복잡해졌나 (근거)

1. **지시 단위로 기능을 더하고 시험 통과로 끝냈다.** 10-19~21 사이 보고 14건, 시험 400여 건이지만 "처음 여는 사람" 관점의 점검은 한 번도 없었다(보고서의 사용성 걸음 수는 전부 Playwright).
2. **MILAL(욥기 논문용 분석기)의 표시를 구조 탭 기본 화면에 넣었다.** 욥기 외 38권에서는 "MILAL 판정: 이 책의 자료 없음"이 떠서 화면이 불완전해 보인다.
3. **같은 일이 여러 메뉴에 있다.** 낱말의 용례 찾기: 본문 낱말 상세의 '찾기' / 연구 '낱말' / 연구 '검색식'. 반복어: 연구 '도구 > 반복' / '비교'. 이론: 연구 '이론' / 각 도구 ⓘ.
4. **코드가 기본 화면에 노출된다.** 구조 줄마다 `WayX` `InfC` `AjCl`, 검색식의 `lex=HNH`(10-20에 근거 설명은 고쳤으나 구조 화면은 그대로).
5. **상태 표시가 연구자용이다.** 승인 상태·파일 해시·대조 실패 수가 일반 사용자 화면에 보인다.

## 3. 기능 분류

| 분류 | 기능 |
|---|---|
| ① 기본 화면에 반드시 | 본문 읽기(원문·번역), 낱말 뜻·형태, 형광펜·괄호, 절/구간 메모, 구조(계층·발화·색), 연구 시작의 목적 카드 4개, 기록 목록·본문으로 돌아가기 |

## 4. 두 판에 대한 판단

첫 판이 단순했던 것은 기능이 적어서이지 설계가 좋아서가 아니다(홈 화면을 거쳐야 했고, 검색식은 빈 상자였다). 현재 판의 문제는 기능이 많아서가 아니라 **전문 기능과 기본 기능이 같은 높이에 놓여 있어서**다. 그래서 이번 시안은 기능을 빼지 않고 높이를 나눈다: 기본은 우리말·목적 중심, 전문은 스위치 하나 뒤.
