## 8. 3차 — "더 복잡해요": 픽트리 방식으로 다시 (2026-10-21 오후)

목사님 의견: 2차의 '절 누름 → 단추 줄 → 낱말 고르기 → 표시하기'는 오히려 단계가 늘었다. **본문에서 바로 글자를 끌어 고르면** 형광펜·밑줄·괄호·복사·노트가 나오고, **본문 창의 단추 하나**로 원어 분석이 나와야 한다(픽트리처럼).

고친 것 (preview.html 에만):
- 2차의 단추 줄·낱말 고르기 단계는 **없앰**. 절을 눌러도 아무것도 펼쳐지지 않음(글자 고르기를 방해하지 않게).
- 히브리어 글자를 길게 눌러 끌어 고르면 화면 아래(하단 메뉴 바로 위)에 도구 줄: 형광펜 **4색 동그라미**(누르면 바로 칠함) · 밑줄 · ⟦ ⟧ 괄호 · 복사하기 · 노트에 추가. 휴대전화가 띄우는 '복사·공유' 말풍선(선택 위쪽)과 겹치지 않게 아래에 둠. 여러 절에 걸쳐 골라도 됨(같은 장 안).
- 번역 글을 고르면 복사하기·노트에 추가만(표시는 히브리어 낱말 단위로 저장되므로 — 번역 글에 칠하려면 새 저장 형식이 필요해 이번에는 하지 않음).
- 노트에 추가: 한 절이면 절 메모, 여러 절이면 구간 메모 — 고른 원문이 관찰 칸에 미리 들어감. 복사는 "본문 (창 22:1)" 형태.
- 원어 분석: 절마다 오른쪽 아래 작은 **"원어 ▾"** 단추(픽트리의 연결 아이콘 자리). 누르면 기존 낱말 띠·문법·스트롱·메모가 그 절 아래에 열리고 "원어 닫기 ▴"로 닫힘.
- 칠한 낱말을 누르면 기존처럼 그 표시 고치기·지우기.
- 저장 형식(kind mark·style·color·word_ids)은 그대로 — 기록·동기화·인쇄·운영 화면에 똑같이 보임.

탭 수: 형광펜 — 원래 6회 → **고르기 + 1회**(색). 밑줄·괄호 — 고르기 + 1회. 메모 — 고르기 + 1회.

시험 `ux_preview.js` 26건 통과(합성 선택으로 확인 — **휴대전화의 실제 길게 누르기 동작은 목사님 확인이 필요**). 화면: `ux3_select_popup` · `ux3_highlighted` · `ux3_vinfo`.

확인 부탁: ① 안드로이드에서 길게 눌러 끌 때 아래 도구 줄이 뜨는지, 휴대전화 자체 말풍선과 부딪히지 않는지 ② "원어 ▾" 단추 자리·이름 ③ 번역 글에도 형광펜이 필요한지(필요하면 저장 형식 추가를 설계해 따로 여쭙겠습니다).

- **운영 반영**: `index.html` 이 새 화면을 기본으로 씁니다(`window.UX2=!/[?&]ux=0/.test(location.search)`). 주소 끝에 `?ux=0` 을 붙이면 옛 화면이 그대로 열립니다(되돌리기용·옛 시험용). `preview.html` 은 늘 새 화면.
- **번역 글(한국어) 칠하기**: 한 절 안의 번역 글을 끌어 고르면 형광펜 4색·밑줄·괄호·복사·노트. 저장은 같은 `kind:"mark"` 에 `anchor.tr={id:"krh",from,to,text}`(글자 위치)를 더하고, `word_ids` 에는 그 절의 히브리어 낱말 번호를 넣어 **Firestore 규칙을 바꾸지 않고** 그대로 통과(규칙 시험 99 PASS). 히브리어 표시와는 섞이지 않고, 번역 본문이 바뀌어 글자가 맞지 않으면 그리지 않습니다. 기록 탭에는 "번역 「아브라함」"으로 보임. (인쇄용 문서에는 아직 번역 글 표시가 나오지 않습니다 — 다음 손볼 곳.)
- **구조의 빈 공간**: '계층 · 발화' 띠가 세 칸(지도 자리) 틀에 두 단추만 있어 오른쪽이 비었던 것 → 기본 화면에서는 두 칸으로. 전문 보기에서만 세 칸.
- **본문 위 빈 공간**: 혼자 있던 '가− 가+' 줄을 없애고 도구 줄(구간 메모·표시 숨기기) 오른쪽으로 옮김. 한 장만 볼 때 아래 장 제목도 없음(3차).
- 원어 분석 아래의 '표시(형광펜·괄호)' 단추는 새 화면에서 뺌(글자 고르기로 대신).
- 시험: 새 화면 `ux_preview.js` 30건(번역 칠하기·두 표시 공존·기록 목록·두 칸 띠·index 기본값) + 옛 화면(`?ux=0`) 회귀 전부 통과. 옛 시험 파일들은 `index.html?ux=0` 을 열도록 바꿨습니다(옛 화면 동작이 그대로인지 계속 확인).
