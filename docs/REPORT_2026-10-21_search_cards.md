# 쉬운 검색(조건 카드) · 고급 검색 구분 · 보완 — 2026-10-21

GPT의 검색 화면 제안을 평가한 뒤 목사님이 승인한 범위(따를 것·넓힐 것 전부, 욥기 발화 구간은 예시로)를 구현했다.

## 1. 쉬운 검색(조건 카드) — 새 화면의 검색 첫 화면
- **무엇을 찾으시나요? 낱말 / 절** 을 먼저 고른다. '문장'은 BHSA에 찾을 조건이 없어 넣지 않았다.
- **카드 하나 = 낱말 하나.** 카드 안의 조건은 모두 같은 낱말이 갖춰야 한다(화면에 적음).
- **＋ 같은 절 안의 다른 낱말 더하기** → 카드가 늘고, 카드 사이에 순서(순서 상관없이 / 앞 낱말보다 뒤에 / 바로 뒤에)를 고른다.
  - 엔진은 형제 상자가 같은 낱말에 걸릴 수 있으므로, 순서로 갈리지 않는 짝에는 `w1 # w2`를 자동으로 붙인다.
  - 시험(요나 1–4장, 명사 카드 2개): # 없이 456묶음 중 220묶음이 '같은 낱말 두 번'이었고, 카드 결과는 236묶음 = 456 − 220.
- **문장 속 역할**(주어·목적어…)은 낱말 카드의 조건이다. 내부적으로는 `phrase function=…` 안의 낱말이 된다.
- **용어:** '아무거나' → '조건 없음', '종류' → '절의 종류'(코드 대신 봐이크톨·완료·명사문 같은 갈래). '안 어디든'은 카드 화면에 아예 없다.
- **읽어 보면:** 카드가 바뀔 때마다 우리말로 보인다. 예: "요나 1–4장의 절 가운데, ① 명사인 낱말, ② 명사인 낱말 — 이 낱말들이 함께 들어 있는 절을 찾습니다. ①·②는 서로 다른 낱말입니다."
- **의미 보존:** 카드 → 상자(S.qb) → TF 식 → 같은 엔진·같은 워커로 실행한다. 엔진(study_qe.js)은 바꾸지 않았다.
  - 시험 1: 카드 실행 건수 = 같은 식 엔진 직접 실행 건수 (보라 1,060 · 인물의 말 속 명령형 4,301).
  - 시험 2: 예시 식(예시1·예시2·서술명사문·인물)은 카드 ↔ 식 왕복에서 qCanon이 같다. '보라 뒤 분사'는 369건으로 기존 대조값과 같다.
  - 카드로 담을 수 없는 식('맨 앞에', 이름 관계, 정규식, 여러 겹)은 고급 검색으로 열고, 카드로 옮기지 않는다(이유 안내).

## 2. 고급 검색 구분
- 카드 화면 아래에 점선 상자를 두고 **[고급 검색] Text-Fabric 검색식** 표지를 단다. '고급 검색식으로 열기'를 누르면 카드 조건이 그대로 식으로 옮겨진다.
- 고급 검색 화면은 위에 붉은 띠와 '고급 검색' 표지, '← 쉬운 검색(조건 카드)으로' 단추를 둔다.
- 연구 첫 화면 카드는 "문법·문장 모양으로 찾기 — … · 고급 검색(TF 검색식)도 여기서"로 바꿨다.

## 3. 결과 보기 전환
- 결과에 **절 목록 / 맞은 낱말 모아 보기** 를 둔다.
- 모아 보기는 낱말 카드마다 맞은 낱말을 사전형별로 세고, 형태(줄기·형태)별 개수를 붙인다. 워커가 낱말 상자별 낱말 번호를 함께 보낸다(워커 v2).
- 줄을 누르면 그 낱말의 다른 용례(구약 전체)를 연다.

## 4. 본문에서 검색 시작
- 원어 분석에 **이 낱말 모양으로 찾기** 를 둔다. 사전형과, 동사라면 줄기·형태가 채워진 카드로 넘어간다.
- '← 본문으로 돌아가기'와 휴대전화 뒤로 가기로 본문의 같은 자리로 돌아온다.

## 5. 욥기 말하는 이별 구간(예시)
- 욥과 세 친구 3–31장, 엘리후 32–37장, 하나님 38–41장(목사님 제공 경계)을 찾는 곳 바로가기로 넣었다.
- 넣은 곳: 검색 카드 화면, 위 주소 단추의 '찾는 곳' 창.
- 장 단위라 장 안의 서술 문장(32:1–5, 38:1)이나 짧은 대답(40:3–5)도 들어간다는 점을 화면에 밝혔다.

## 6. 함께 고친 것(목사님 화면 확인 중 지적)
- 연구 첫 화면 안내: "살펴볼 곳은 현재 요나 1장입니다."
- **장면 도구 0곳 vs 검색식 3건(요나 1장).**
  - 원인: 도구는 봐예히 가운데 주어 없이 뒤에 때·'키'·곳이 이어지는 것만 센다. 요나 1:1·1:4·1:17의 봐예히는 모두 주어가 붙은 '…이 있었다' 문장이다.
  - '이 결과의 검색식 보기'는 이 규칙을 담지 못한 넓은 식이었다.
  - 고침 ①: 도구 결과에 세는 규칙을 적었다.
  - 고침 ②: "봐예히가 있지만 세지 않은 곳 N곳 — 왜 뺐는지"를 펼쳐 볼 수 있게 했다.
  - 고침 ③: 단추 이름을 "검색식으로 비슷하게 찾아보기"로 바꾸고, 결과가 더 많을 수 있다고 적었다.
- 검색식을 우리말로 읽을 때 `domain#Q`가 그대로 보이던 것을 "인물의 말이 아닌"으로 바꿨다.
- **두 본문 비교에서 같은 말이 되풀이되던 문제.**
  - 원인: '바사 왕 고레스'처럼 한쪽이나 양쪽에 여러 번 나오는 말은 짝마다 한 줄씩 생겼다.
  - 고침: 같은 낱말 순서를 한 줄로 묶고 나온 자리를 함께 적는다("같은 말이 A에 3번, B에 2번 나옴"). 더 긴 연쇄 안에 양쪽 모두 이미 들어 있는 조각은 뺐다.
  - 대하 36:22–23 ↔ 스 1:1–3 은 8줄에서 2줄로 줄었다. 칠하기(노란색)는 나온 자리 전부에 그대로 둔다.
